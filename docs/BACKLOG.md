# 개선 메모 (대기 중)

2026-11-19 머성 요청. 아직 착수하지 않음. 각 항목은 기획 → 리뷰 → 승인 후 개발 순서로 진행.
적용 범위는 거래소 검색 창(`Ctrl+D`)으로 가정함. 착수 전에 확인할 것.

## 1. 지역 레벨 아이템의 기본 체크
- 대상: 지도, 강탈 계약, 강탈 도면 등 지역 레벨이 있는 아이템 전부
- 창이 뜰 때 **지역 레벨 또는 몬스터 레벨만 체크**하고, 나머지 조건은 전부 해제한 상태가 기본값

## 2. 타락 아이템의 '타락 아님' 기본 해제
- 타락한 아이템을 검색할 때 `타락 아님` 조건을 기본으로 체크 해제

## 3. 옵션 나열 순서
- 아이템 옵션을 복사 원문의 위에서 아래 순서대로 나열

## 4. 같은 옵션은 합산
- 같은 옵션이 여러 줄 있으면 하나로 합산해 검색 조건에 적용
- 예: 생명력 최대치

## 5. 아이템 종류별 검색 템플릿
- 목적: 종류별 기본 체크와 허용 품목을 한곳에서 관리. 판별·검색 로직은 그대로 두고 표로만 분리
- 1·2번 항목은 이 템플릿의 기본값으로 처리
- 템플릿 5개
  - 장비: 한손·양손 무기, 방어구, 장신구(반지·목걸이·허리띠·화살통), 주얼(일반·심연·성단)
  - 지역 레벨 아이템: 지도(일반·악몽·바알 사원·쉐이퍼 수호자·고유), 강탈 계약·도면, 원정 기록서(추가 지원)
  - 젬: 스킬 젬, 보조 젬 (변형·바알 젬은 차단 유지)
  - 플라스크: 생명력·마나·혼합·유틸리티 플라스크 (2026-11-19 머성 결정으로 별도 분리)
  - 기타: 살덩이, 금지된 서 등 확인된 품목만 허용. 나머지는 "지원하지 않는 품목"으로 일괄 차단
- 2026-11-19 머성 결정: 지역 레벨이 있지만 아직 미지원인 아이템도 지원 대상에 추가
  - 우선 원정 기록서. 그 밖의 대상은 기획 단계에서 전수 조사해 목록 확정
  - 품목마다 카카오 거래소 확인 링크로 검증한 뒤 연다. 확인 전에는 지금처럼 차단
