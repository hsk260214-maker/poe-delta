# 개선 메모

각 항목은 기획 → 리뷰 → 승인 후 개발 순서로 진행. 완료한 항목은 지우지 않고 맨 아래 `완료` 구역으로 옮겨 둔다.
적용 범위는 거래소 검색 창(`Ctrl+D`).

## 진행 대기

### 3. 옵션 나열 순서
- 아이템 옵션을 복사 원문의 위에서 아래 순서대로 나열
- 머성 결정: 종류별 제목·구분선은 유지하고, 순서가 어긋난 경우만 고친다. 어긋난 아이템의 `Ctrl+C` 원문이 있어야 착수

### 5-1. 원정 기록서 등 지역 레벨 아이템 추가 지원
- 2026-11-19 머성 결정: 지역 레벨이 있지만 아직 미지원인 아이템도 지원 대상에 추가
  - 우선 원정 기록서. 그 밖의 대상은 기획 단계에서 전수 조사해 목록 확정
  - 품목마다 카카오 거래소 확인 링크로 검증한 뒤 연다. 확인 전에는 지금처럼 차단

## 완료 (읽지 않아도 됨)

### [완료 v1.2.7] 6. 거래소 검색 결과 개수
- 게임 위 시세 모드에서 처음 불러올 매물 수를 설정(10~100, 기본 20)하고, 결과 표 끝에서 10개씩 이어 불러오기(`FEAT-010`)
- 실제 거래소 동작은 모의 응답으로만 검증

### [완료 v1.2.7] 7. [버그] `두 번 타락` 아이템을 타락으로 인식하지 못함
- `두 번 타락`·`Twice Corrupted`를 타락으로 인식(`FIX-011`). 견본: 머성 제보 코발트색 주얼 `천공인 눈`
- 2026-11-20 머성 결정으로 타락한 아이템은 다시 `타락`을 체크한 상태로 연다(지역 레벨 아이템 제외)

### [완료 v1.2.6] 1. 지역 레벨 아이템의 기본 체크
- 대상: 지도, 강탈 계약, 강탈 도면 등 지역 레벨이 있는 아이템 전부
- 창이 뜰 때 **지역 레벨 또는 몬스터 레벨만 체크**하고, 나머지 조건은 전부 해제한 상태가 기본값

### [완료 v1.2.6] 2. 타락 아이템의 '타락 아님' 기본 해제
- 타락한 아이템을 검색할 때 `타락 아님` 조건을 기본으로 체크 해제
- 머성 결정 "타락 아이템만 해제"로 구현했으나 v1.2.7에서 되돌림(7번 참고)

### [완료 v1.2.6] 4. 같은 옵션은 합산
- 같은 옵션이 여러 줄 있으면 하나로 합산해 검색 조건에 적용. 예: 생명력 최대치, 에너지 보호막 % 증가
- 머성 결정: 같은 종류 안에서만, 실검증 생략하고 조건에 맞는 모든 옵션에 적용(`FIX-010`)

### [완료 v1.2.6] 5. 아이템 종류별 검색 템플릿
- 종류별 기본 체크를 한곳에서 관리(`FEAT-008`). 판별·검색 로직은 그대로
- 템플릿 5개: 장비, 지역 레벨 아이템, 젬, 플라스크, 기타
- 남은 원정 기록서 지원은 위 5-1로 분리
