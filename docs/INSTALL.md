# POE Delta 설치·사용 설명서

POE Delta는 Path of Exile 1용 Windows 프로그램입니다. 원작자 KyungseokKANG의 [Exile Delta](https://github.com/KyungseokKANG/exile-delta)(MIT)를 바탕으로 hsk260214-maker가 기능을 더한 커스텀판입니다.

| 기능 | 출처 |
|---|---|
| **템 비교:** 게임에서 아이템에 `Ctrl+C`를 누르면, 그 템을 지금 캐릭터에 꼈을 때 DPS·EHP·최대 피격이 얼마나 바뀌는지 게임 위에 보여 줍니다. 계산은 Path of Building(PoB) 엔진으로 합니다. 캐릭터 불러오기, 패시브 트리, 젬, 지도 경고 등도 포함합니다. 한글 클라이언트를 지원합니다. | 원본 Exile Delta 기능 |
| **거래소 시세 검색:** 아이템에 `Ctrl+D`를 누르면, 비슷한 옵션의 가판대(즉시 구매) 매물을 거래소(기본: 카카오 거래소)에서 찾아 줍니다. | POE Delta 추가 기능 |

아래 각 절 제목에도 출처를 표시했습니다. 원본 기능의 자세한 설명은 [원본 README](https://github.com/KyungseokKANG/exile-delta#readme)에 있습니다.

## 1. 준비

- Windows 10 또는 11
- Path of Exile 1의 화면 모드를 **창 모드 전체 화면(Windowed Fullscreen)**으로 설정합니다. 전체 화면(Exclusive)에서는 프로그램 창이 게임 위에 보이지 않습니다.
- Python 같은 다른 프로그램은 설치하지 않아도 됩니다.

## 2. 설치

1. 이 저장소의 [Releases](https://github.com/hsk260214-maker/poe-delta/releases/latest) 페이지에서 `PoeDelta-버전.zip`을 받습니다. 같은 페이지의 `app-버전.zip`, `manifest.json`은 프로그램이 업데이트할 때 쓰는 파일이라 받지 않아도 됩니다.
2. 압축을 원하는 폴더에 풉니다. 바탕화면이나 `내 문서` 아래도 괜찮습니다. 안에는 `PoeDelta.exe`와 라이선스 파일 2개가 있습니다.
3. `PoeDelta.exe`를 실행합니다.
   - 서명되지 않은 프로그램이라 처음에 Windows가 "PC 보호" 경고를 띄울 수 있습니다. **추가 정보 → 실행**을 누르면 됩니다.
   - 백신이 막으면 이 파일을 예외로 등록해 주세요. Python으로 만든 실행 파일은 가끔 잘못 검출됩니다.
4. 처음 실행하면 계산에 쓰는 PoB 엔진(약 370MB)을 PoB 공식 GitHub에서 한 번 받습니다. 몇 분 걸릴 수 있습니다.

## 3. 캐릭터 등록 (원본 Exile Delta 기능, 리그별 보기는 POE Delta 추가 기능)

캐릭터 화면에서 `+`를 누른 뒤 두 방법 중 하나로 불러옵니다.

**계정으로 불러오기 (자동 갱신 가능)**

1. 계정 사이트의 개인정보 설정에서 **캐릭터 탭을 공개**로 바꿉니다.
   - 해외 계정: pathofexile.com → 내 계정 → Privacy Settings
   - 카카오 계정: poe.kakaogames.com의 계정 설정
2. **캐릭터 이름이 아니라 계정명**을 넣습니다. 계정명 뒤에 `#1234` 같은 번호가 있으면 함께 넣습니다. 한글 계정명은 사이트에서 그대로 복사해 붙여 넣는 것이 안전합니다.
3. 목록에서 캐릭터를 고릅니다. 카카오 계정도 해외 PC 서버에 속해 있어 같은 방법으로 불러올 수 있습니다.

목록을 받으면 `전체`와 계정에 있는 리그 단추가 캐릭터 수와 함께 나옵니다. 리그를 누르면 해당 캐릭터만 보이며, 마지막에 직접 고른 리그를 기억합니다. 단추가 많으면 가로로 스크롤할 수 있습니다. 이 리그별 보기는 POE Delta 추가 기능이며 등록 후의 캐릭터 탭은 바꾸지 않습니다.

**PoB 코드나 링크로 불러오기**

PoB에서 만든 빌드 코드나 pobb.in 같은 링크를 붙여 넣습니다. 이 방법은 리그 정보가 없어서, 거래소 검색 때 리그 이름을 한 번 직접 넣어야 합니다(5절).

"1분마다 갱신"을 켜 두면 레벨업, 장비 교체, 패시브 변경이 알아서 반영됩니다(계정으로 불러온 경우).

## 4. 템 비교 (`Ctrl+C`) (원본 Exile Delta 기능)

게임에서 아이템 위에 마우스를 올리고 `Ctrl+C`를 누르면 옵션변경 창이 뜹니다.

- 낄 자리마다 Full DPS, EHP, 최대 피격(물리·화염·냉기·번개·카오스) 변화를 보여 줍니다.
- 저항이 상한 밑으로 떨어지거나 능력치 요구치가 모자라면 경고합니다.
- 옵션을 끄거나 수치를 바꾸거나 implicit을 붙여 보면서 바로 다시 계산할 수 있습니다.
- 지도에 `Ctrl+C`를 누르면, 캐릭터 화면 "비선호 지도" 탭에서 골라 둔 위험 옵션이 있는지 알려 줍니다.

메뉴(☰)의 "게임 Ctrl+C 감지"로 이 기능을 끄고 켤 수 있습니다.

## 5. 거래소 시세 검색 (`Ctrl+D`) (POE Delta 추가 기능)

1. 게임에서 아이템 위에 마우스를 올리고 `Ctrl+D`를 누릅니다. PoE 창이 앞에 있을 때만 동작하고, 다른 프로그램의 `Ctrl+D`는 그대로입니다.
2. 검색 조건 창이 뜹니다. 옵션마다 체크와 최소·최대값을 조정합니다. 최소값은 실제 수치의 90%로 미리 채워집니다.
3. 검색 버튼이나 `Enter`를 누릅니다.

- **대상:** 식별된 레어·유니크 장비(무기·방어구·장신구·화살통)와 주얼. 그 밖의 아이템은 "아직 지원하지 않습니다"라고 나옵니다.
- **회색 옵션:** 거래소 옵션과 확실히 맞출 수 없는 줄은 회색으로 표시되고 검색 조건에서 빠집니다. 마우스를 올리면 이유가 나옵니다.
- **가판대 매물만:** 판매자가 오프라인이어도 바로 살 수 있는 가판대(즉시 구매) 매물만 검색합니다.
- 옵션변경 창의 "거래소 검색" 버튼도 같은 검색을 엽니다. 이때도 옵션변경 창에서 바꾼 내용이 아닌, 복사해 온 원래 아이템으로 검색합니다.

### 검색 방식

메뉴(☰) → "거래소 설정"에서 고릅니다.

| 방식 | 동작 |
|---|---|
| 브라우저 모드 | 조건이 채워진 거래소 페이지를 기본 브라우저로 엽니다. 거래소 사이트가 로그인을 요구하면 브라우저에서 로그인합니다. |
| 게임 위 시세 모드 (기본) | 검색 버튼을 누르면 가격이 싼 순서대로 최대 20개 매물과 요약을 게임 위 창에 보여 줍니다. |

### 리그

계정으로 불러온 캐릭터는 리그가 자동으로 들어갑니다. PoB 코드로 불러왔다면 검색 창이나 "거래소 설정"의 리그 칸에 리그 이름을 넣습니다. 예를 들어 지금 챌린지 리그 이름이나 `Standard`를 넣습니다. 한 번 넣으면 기억합니다. 리그 이름은 거래소 사이트 왼쪽 위의 리그 선택 목록에서 볼 수 있습니다.

### 서버 (카카오 거래소)

처음 사용하면 카카오 거래소(`poe.kakaogames.com`, 한글 클라이언트용)가 기본입니다. 영문 클라이언트라면 "거래소 설정"에서 서버를 "공식"으로 바꿔야 검색됩니다. 이미 골라 둔 검색 방식과 거래소는 그대로 유지됩니다.

### 그 밖의 설정

- **기본 최소값 비율:** 0.9가 기본값입니다. 0.8로 바꾸면 최소값을 실제 수치의 80%로 채웁니다.
- **단축키:** `Ctrl+D` 사용을 끄고 켭니다. Awakened PoE Trade처럼 `Ctrl+D`를 쓰는 프로그램을 같이 켜 두면 "Ctrl+D를 다른 프로그램이 쓰고 있습니다"가 뜹니다. 둘 중 하나만 쓰세요.
- **POESESSID, 연락처:** 게임 위 시세 모드에서만 쓰는 선택 항목입니다. 비워 둬도 됩니다.

## 6. 업데이트 (원본 Exile Delta 구조, 받는 곳만 POE Delta에서 변경)

프로그램을 켤 때마다 이 저장소에 새 버전이 있는지 확인합니다.

- 새 버전이 있으면 바뀐 내용을 보여 주고 업데이트할지 묻습니다. "지금 업데이트"를 누르면 몇 초 만에 받아서 다시 켜집니다.
- 메뉴(☰) → "프로그램 업데이트 확인"으로 직접 확인할 수도 있습니다.
- 가끔 "새 설치 파일이 필요합니다"가 뜨면 Releases 페이지에서 새 `PoeDelta-버전.zip`을 받아 덮어씁니다. 설정과 캐릭터는 그대로 남습니다.
- 새 버전이 켜지다가 계속 실패하면 알아서 이전 버전으로 돌아갑니다.

원작자의 Exile Delta 업데이트로 바뀌지는 않습니다.

## 7. 원본 Exile Delta와 함께 쓰기 (POE Delta 변경 사항)

- POE Delta와 원본 Exile Delta는 설정과 데이터를 따로 저장해서 동시에 켜도 됩니다.
- 원본을 쓰던 PC에서 POE Delta를 처음 켜면 원본의 설정과 캐릭터를 **복사**해 옵니다. 원본 파일은 바꾸지 않습니다.
- PoB 엔진은 따로 한 번 더 받습니다.
- 원본 설정을 가져오지 못했다는 안내가 뜨면 그번 실행은 임시 설정으로 켜지고, 다음 실행 때 다시 가져옵니다.

## 8. 파일 위치와 삭제

| 내용 | 위치 |
|---|---|
| 설정, 등록한 캐릭터 | `%APPDATA%\PoeDelta\` |
| PoB 엔진, 받은 업데이트, 로그 | `%LOCALAPPDATA%\PoeDelta\` |

지우려면 압축을 푼 폴더와 위 두 폴더를 삭제합니다. 탐색기 주소창에 `%APPDATA%`처럼 그대로 쓰면 그 폴더가 열립니다.

## 9. 문제가 생길 때

| 증상 | 해결 |
|---|---|
| 게임 위에 창이 안 보임 | 게임을 창 모드 전체 화면으로 바꿉니다. |
| 창을 닫아도 게임으로 키보드가 돌아가지 않음, 단축키가 안 먹음 | 게임을 관리자 권한으로 켰다면 POE Delta도 관리자 권한으로 실행합니다. |
| `Ctrl+D`가 안 됨 | PoE 창이 앞에 있는지, 다른 프로그램이 `Ctrl+D`를 쓰고 있지 않은지, "거래소 설정"에서 단축키가 켜져 있는지 확인합니다. |
| 계정으로 캐릭터를 못 불러옴 | 캐릭터 탭 공개 설정, 캐릭터 이름이 아닌 계정명인지, `#1234` 번호를 확인합니다. 그래도 안 되면 PoB 코드로 불러옵니다. |
| "리그 이름을 입력하세요" | 5절 "리그"를 참고해 리그 이름을 넣습니다. |
| "검색 조건이 너무 깁니다" | 켜 둔 옵션 몇 개를 끕니다. |
| 영문 아이템을 카카오 서버로 검색할 수 없음 | "거래소 설정"에서 서버를 "공식"으로 바꿉니다. |
| 업데이트 확인에서 "확인할 수 있는 릴리스가 없습니다" | 아직 새 버전이 없거나 저장소에 접근할 수 없는 상태입니다. 지금 버전을 그대로 쓰면 됩니다. |
