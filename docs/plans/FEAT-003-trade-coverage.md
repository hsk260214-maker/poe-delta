# FEAT-003 거래소 검색 확대

상태: 기획 수정안 v2.2, 3차 리뷰 대상. 참조: Awakened PoE Trade `803d188d1359c4d5b1e3826da5dc680ea74a158f`. 기존 미커밋 거래소 기본 설정 변경은 독립 변경으로 보존하며 이 기능의 승인 범위에 포함하지 않는다.

## A. 영향력 및 옵션 선택

- 아이템의 한·영 플래그로 쉐이퍼, 엘더, 십자군, 대속자, 사냥꾼, 전쟁군주를 각각 표시한다. 부여된 전통 영향력은 기본 체크하고, 사용자가 체크를 해제하면 해당 조건을 뺀다. 체크한 영향력만 공통 쿼리에 AND 조건으로 추가한다. 고정 APT 데이터에서 이 6개의 `pseudo.pseudo_has_*_influence`만 추출하고, 생성 검증에서 각 예상 ID와 대조한다.
- 총주교·포식자 아이템 플래그는 이름으로 표시하되, 확인되지 않은 아이템 단위 거래소 키는 전송하지 않는다. 대신 매칭된 해당 고정 옵션을 줄별로 선택할 수 있게 한다. 거래소 ID가 없거나 출처가 모호한 줄은 추측하지 않고 사유를 표시한다. 둘 다 부여된 경우 각각 표시한다.
- 고정과 일반 옵션을 다른 구역에 두고, 제작·분열·인챈트는 배지로 구분한다. 총주교·포식자 표시는 기존 `mod.sub`를 재사용한다. 체크나 최소·최대 변경은 검색 실행 전에는 네트워크 요청을 일으키지 않는다.
- 검증: 한·영 복사본, 이중 전통 영향력, 총주교·포식자 동시 부여, 체크 전환과 양 모드 공통 쿼리. 단독으로 되돌릴 수 있도록 검색 품목 확대와 변경 단위를 분리한다.

## B. 일반·마법 장비, 플라스크, 지도 및 젬

- 동일한 고정 APT 커밋의 한·영 `items.ndjson`에서 품목 분류, 현지 이름, 정규 베이스와 거래소 식별에 필요한 필드만 추출한다. 기존 `dict_builder.apt_ndjson`과 고정 커밋 캐시 분리를 재사용한다. 추출 전에 묶음 구조와 실제 필드·라이선스를 확인하고, 출처와 커밋을 생성물에 기록한다. 품목 분류·제작 가능 여부·필요한 discriminator를 신뢰할 수 있게 추출하지 못하면 B를 멈추고 기획에 보고한다. 런타임에는 고정 로컬 자료만 읽는다.
- 일반·마법 장비(반지 포함)는 베이스와 `normal`/`magic` 등급 조건을 함께 보낸다. 마법 플라스크·지도에도 같은 원칙을 적용한다. 마법 표시 이름 전체를 베이스로 보내지 않는다. 원본 분류 안에서 정확히 일치하는 베이스를 우선하고, 없으면 APT의 언어별 마법 이름 처리와 같은 방식으로 제작 가능한 후보 중 가장 긴 베이스를 고른다. 후보가 모호하거나 변형을 식별할 수 없으면 안내하고 검색을 막는다. 스크린샷의 `차원의 토파즈 반지 - 레인저`는 게임 복사 원문 확보 전까지 변형을 추측하지 않는다.
- 플라스크는 베이스·등급을, 고유 플라스크와 고유 지도는 고유 이름과 베이스를 사용한다. 지도는 베이스 및 티어를 사용하고, 공통 지도 베이스 `Map`은 고정 APT에서 확인한 `map` discriminator를 적용한다. 액티브·보조 젬은 이름, 레벨, 퀄리티를 조건으로 사용한다. 영문 머리줄과 한글 머리줄은 APT 고정 커밋의 클라이언트 문자열 및 기존 `mapcheck`/`ko2en` 정의를 대조하고, 젬 레벨의 최대 표시가 있는 한글 복사 예시를 테스트한다.
- 쉐이퍼 수호자 지도는 베이스로, 엘더 수호자 점령·정복자 성채·복사본에 표시된 지역 영향력은 고정 APT의 해당 ID로 구분한다. 점령 조건은 예를 들어 `{"id":"implicit.stat_3624393862|1"}` 그대로 보내며 별도 `value`를 붙이지 않는다. 정체성 필터를 끄거나 제거하여 더 넓게 검색하지 않는다. **출시 전** 공식 검색 1회와 브라우저 링크 1회로 수호자가 정확히 좁혀지는지 확인한다. 매물이 없거나 결과를 확인할 수 없으면 해당 필터를 활성화하지 않는다. **실행 중** 검증을 통과한 조건에 매물이 0개면 기존 ‘검색 결과 없음’을 표시한다. 표현할 수 없는 정체성은 검색을 막고 이유를 안내한다. 기존 기름 부여 목걸이의 `|` ID 형태도 회귀 검사한다.
- 젬의 레벨과 퀄리티는 복사본 수치를 최소값으로 보내고, 타락 여부는 기존 장비와 같은 조건으로 유지한다.
- 첫 범위에서는 변형·바알 젬과 역병·역병에 황폐해진 지도는 일반 젬·지도에 합치지 않고 검색을 막아 안내한다. 미확인 품목은 기존처럼 지원하지 않는다. 나머지 품목도 정체성을 보존할 수 없는 경우 검색을 막는다.
- 검증: 한·영 일반·마법 반지, 마법 플라스크와 마법 지도 각 언어 1건 이상, 고유 플라스크·지도, 지도 점령 값, 액티브·보조 젬, 지원하지 않는 변형, 기름 부여 목걸이의 예상 쿼리와 링크. 스크린샷 반지의 정확한 종류를 확인하기 전에는 비슷한 이름으로 대체하지 않는다.

## 공통 기준

### 후속 범위: 장비 종류 검색과 옵션 전환

- A/B와 별도 승인 범위이며 B의 고정 APT 베이스 분류 자료에 의존한다. 지원되는 희귀 이하 장비는 기본값으로 동일 장비 종류를 검색한다. 베이스 버튼을 켜면 카테고리 대신 정확한 정식 `type`만 보낸다. 공식은 영문, 카카오는 동일 베이스의 정식 한글 이름을 사용한다. 고유·플라스크·지도·젬의 기존 정체성 조건은 바꾸지 않는다.
- 기본 검색은 `type`과 `name` 없이 `type_filters.filters.category.option`을 보낸다. 베이스별 품목 분류를 고정 APT의 `CATEGORY_TO_TRADE_ID`로 매핑한다. 예: `armour.helmet`, `accessory.ring`, 찌르기 한손 검 `weapon.onesword`, 일반·어비스·성단 주얼 `jewel`·`jewel.abyss`·`jewel.cluster`. 베이스는 확정됐으나 매핑이 없으면 기존 정확 베이스 검색만 허용하고, 베이스도 모호하면 검색을 막는다.
- 희귀 장비의 카테고리 검색은 `nonunique`로 고유를 제외한다. 이 조건은 일반·마법 매물을 배제하지 않는다. 일반·마법 장비는 두 검색 범위 모두 B에서 정한 `normal`/`magic` 조건을 유지하며, 일반 등급도 사용자의 요청대로 카테고리 검색이 기본이다. 희귀 장비의 정확 베이스 검색은 기존 등급 규칙을 유지한다.
- 일반·분열 옵션 줄에서만 전환을 제공한다. 동일하게 확정한 stat 항목에 양쪽 ID가 모두 있을 때만 전환하며, 다른 ID를 접두어로 합성하지 않는다. 체크 상태와 값은 유지하고 대상 ID의 부호 규칙을 적용한다. 상대 ID가 없으면 이유를 표시한다. 고정·제작·인챈트에는 전환을 추가하지 않는다.
- 완료 기준: 투구·반지·찌르기 한손 검·일반/어비스/성단 주얼의 카테고리 쿼리와 정확 베이스 쿼리를 확인한다. 한·영 현지 이름, 희귀 카테고리의 `nonunique`, 일반·마법 등급 유지, 전환 가능한 옵션 및 상대 ID가 없는 select 묶음을 검증한다. 토글만으로 요청하지 않으며 두 검색 모드는 같은 쿼리를 쓴다.

### 일반·마법 등급의 추가 기준

- 공통 `build_query`에서 `type_filters.filters.rarity.option`을 `magic` 또는 `normal`로 설정한다. 브라우저 `q`와 인게임 검색 본문을 각각 검사한다. 고정 APT는 `magic` 사용 근거지만 `normal`의 실동작 근거는 아니다. 공식 거래소 검색 1회와 브라우저 링크 1회에서 실제 일반 매물만 반환되는 것을 확인한 뒤 일반 장비·플라스크·지도 검색을 활성화한다. 확인이 불가능하면 세 일반 품목의 검색을 막고 등급 조건을 빼서 재검색하지 않는다. 희귀·고유 장비의 기존 등급 조건은 이번에 바꾸지 않는다.
- 한·영 `Item Class`에 대응하는 베이스 후보만 사용한다. 양 언어의 이름은 같은 원본 베이스 레코드에 연결한다. 공식 거래소에는 정식 영문 베이스, 카카오에는 정식 한글 베이스를 `type`으로 보낸다. 마법 접사명 전체가 `name`이나 `type`으로 들어가면 안 된다. 정확히 일치하는 후보가 없을 때의 마법 베이스 비교는 고정 APT의 언어별 단어 경계를 따르며, 같은 길이의 서로 다른 후보가 남으면 차단한다.
- 품질 표시 `상급`/`Superior`만 베이스 이름에서 제거해도 된다. 한국어와 영어 모두 `ko2en.translate_base`의 일괄 접두어 제거에 의존하지 않는다. 결합·삿된·흔적 등 정체성을 바꾸는 변형은 별도 베이스 또는 검증된 전용 필터가 필요하다. APT에 `foulborn_item`·`vestigial` 키는 있으나 이번 새 범위에서 정확한 전송이 검증되기 전에는 해당 변형을 차단한다. 기존 희귀·고유 동작은 유지한다.
- 일반은 옵션을 모두 끈 채 시작한다. 마법은 매칭된 일반 옵션만 기본 체크하며, 고정 옵션(타락 고정 포함)은 기본 해제하되 개별 선택할 수 있다. 기존 타락 여부 조건은 유지한다. 미확인은 검색하지 않는다.
- 한·영 일반·마법 장비 네 종류의 고정 입력에 대해 공식·카카오 해당 지원 조합의 예상 JSON 및 URL을 고정자료로 검증한다(영문 복사본의 카카오 검색은 기존 제한 유지). 마법은 일반 옵션만 체크한 경우와 고정 옵션만 체크한 경우를 각각 검증하며, 품질 접두와 지원 불가 변형도 확인한다. `차원의 토파즈 반지 - 레인저`의 개별 재현은 게임 복사 원문을 확보한 뒤 별도 고정자료로 검증하며, 원문 없이 `- 레인저`의 의미나 검색 결과를 확정하지 않는다.

가판대(`securable`)만 검색한다. 브라우저 모드에서는 앱이 거래소 HTTP 요청을 하지 않고, 게임 위 모드도 검색 버튼 전에는 호출하지 않는다. 기존 `Ctrl+D` 경로 이후 일반 `Ctrl+C` 지도 경고를 판정하는 순서를 변경하지 않는다. A/B는 별도 변경 단위로 진행하되 이 기획의 리뷰 한도는 다시 시작하지 않는다. 승인 전 코드 수정, 검증 요청, 릴리스 작업은 하지 않는다.
