# FIX-002 거래소 설정에서 카카오 서버를 처음부터 고를 수 있게

- 상태: 기획 v1.1 — 개발 완료 (개발 리뷰 1/3 APPROVED, 테스트 103개 통과). 커밋·릴리스 전
- 브랜치: `custom` (기준 커밋 5d0a4ca, 릴리스 v1.1.0)
- 작성: poe 기획 세션

## 1. 문제 (실제 코드 근거)

| 문제 | 위치 | 결과 |
|---|---|---|
| 서버 목록에 "카카오"가 조건부로만 들어감 | `app/trade/settings_dialog.py:44` `if lang == "ko" and config.KAKAO_ENABLED:` | 프로그램을 켠 뒤 한글 아이템을 한 번 복사하기 전에는 "거래소 설정"에 "카카오"가 없음 |
| `lang`을 마지막 아이템에서 추측 | `app/main.py` `_trade_settings` (L259~), 아이템이 없으면 `"en"` | 위와 같음 |
| **저장값과 화면 표시가 어긋남** | `settings_dialog.py:46` `setCurrentIndex(max(0, findData(저장값)))` | 카카오로 저장해 둔 상태에서 한글 아이템 없이 설정 창을 열면 목록에 카카오가 없어 화면은 "공식"을 보여 주지만, 실제 저장값은 카카오 그대로다 (목록 변경이 없어 저장 안 됨) |

영문 아이템을 카카오 서버로 검색하려 하면 거래소 창이 이미 막아 준다: `query.item_info` → `config.validate_server`가 `ValueError` → `trade_window.load`가 `_error`에 담고 `_validate`가 검색 버튼을 막고 이유를 표시한다 (`app/trade/trade_window.py` L110~114, L190~208). 이 동작은 바꾸지 않는다.

## 2. 바꾸는 것

1. `SettingsDialog`의 서버 목록은 `config.KAKAO_ENABLED`이면 언제나 "공식"과 "카카오 (한글 클라이언트 전용)" 두 개를 보여 준다. `lang` 인자를 없앤다 (서버 목록 말고는 쓰이지 않음, `settings_dialog.py:31`·`:44`).
2. 화면에 보이는 선택이 항상 저장값과 같아야 한다.
   - `server` 키가 없으면(기본값 공식) "공식"을 보여 주고 저장하지 않는다. 설정 창을 열기만 해서 `settings.json`이 바뀌지 않게 하기 위해서다.
   - 저장값이 목록에 없으면(알 수 없는 값, 또는 `KAKAO_ENABLED`가 꺼져 카카오가 없음) "공식"을 보여 주고 **그 값을 바로 저장**한다.
3. `main._trade_settings`는 `lang`을 구하던 코드를 지우고 `SettingsDialog(self)`로 연다. 닫은 뒤 하던 일(`trade_hotkey.poll()`, 열린 거래소 창 다시 불러오기)은 그대로.
4. `config.validate_server`의 카카오 거절 문구를 "카카오 서버는 한글 클라이언트에서만 지원합니다. 거래소 설정에서 서버를 '공식'으로 바꾸세요"로 늘린다. 같은 문구가 거래소 창 안내와 오류에 그대로 쓰인다.
5. `docs/INSTALL.md` 5절 "서버"의 "한글 아이템을 먼저 복사" 순서와 9절 표의 "서버 목록에 카카오가 없음" 줄을 지우고, "영문 클라이언트에서 카카오를 고르면 검색이 막힌다"는 한 줄로 바꾼다.
6. **사실과 다른 안내 문구 삭제:** `app/trade/trade_window.py:137`의 "카카오 서버와 매물·시세가 다를 수 있습니다"(한글 클라이언트 + 공식 서버일 때 표시)를 없앤다. 카카오 서비스는 해외 서버의 일부로 운영되고(공식 포럼 "Path of Exile is Now Available in South Korea"), FEAT-001 실제 요청에서 공식·카카오 search가 같은 total(1553)을 돌려줬다. `docs/INSTALL.md` 5절의 "카카오 계정도 같은 서버라서 매물이 같다"는 그대로 둔다. `docs/plans/FEAT-001-trade-search.md` 6.4의 해당 줄 끝에 "(FIX-002에서 삭제: 같은 서버)"를 덧붙인다.

## 3. 하지 않는 것

서버별 리그 목록 기억, 카카오 서버에서 영문 아이템 검색, 릴리스(v1.1.1)는 머성 요청 때.

## 4. 완료 기준

1. 아이템을 하나도 복사하지 않은 상태에서 "거래소 설정"을 열면 서버 목록에 "공식"과 "카카오 (한글 클라이언트 전용)"가 있다.
2. 카카오를 저장해 둔 뒤 다시 열면 화면도 카카오다. 저장값이 목록에 없으면 화면은 "공식"이고 설정 파일도 "공식"이 된다.
3. 영문 아이템 + 카카오 설정이면 거래소 창의 검색 버튼이 막히고 4번 문구가 보인다. 한글 아이템 + 카카오는 지금처럼 카카오 링크·검색이 된다.
4. 한글 아이템 + 공식 서버로 거래소 창을 열어도 "매물·시세가 다를 수 있습니다" 안내가 나오지 않는다. 설정 창을 열고 닫기만 했을 때 `server` 키가 없던 `settings.json`은 바뀌지 않는다.
5. 기존 테스트(93개)와 새 테스트가 모두 통과한다. `tests/trade/test_window.py`의 `SettingsDialog(lang="ko")` 호출은 새 형태로 맞춘다.

## 5. 테스트 계획

FEAT-001의 격리·네트워크 차단 규칙 그대로. 단위 테스트 4개:
1. 아이템 없이 연 설정 창의 서버 목록.
2. 저장값과 화면 표시: 카카오 → 카카오 / 알 수 없는 값 → 공식(저장됨) / 키 없음 → 공식(파일 안 바뀜).
3. 영문 아이템 + 카카오 설정으로 거래소 창을 불러오면 검색 버튼이 막히고 문구가 보임.
4. 한글 아이템 + 공식 서버에서 안내 문구 없음.
