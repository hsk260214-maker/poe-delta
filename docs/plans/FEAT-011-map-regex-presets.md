# FEAT-011 지도 정규식 프리셋 · 선호/비선호 · 수치 조건

상태: 기획안 v3, 기획 리뷰 3/3 대상(2/3 보완: 지도 속성 값 상한 근거와 1000% 이상 지원 범위, 골든 범위 분리). 출처: 2026-11-20 머성 요청, UI 초안 `E:/dev/design/poe-delta-map-presets.html`.

## 1. 목적

캐릭터 화면의 지도 탭에서 옵션마다 선호·비선호를 고르고, 수치 조건과 함께 프리셋으로 저장한다. 정규식은 참고 사이트(POE Regex KR)와 같은 형식으로 만들고, 앱은 클립보드 복사까지만 한다(사용자가 직접 붙여 넣음). 실제 게임 보관함 호환은 클라이언트 검증 전까지 주장하지 않는다.

## 2. 현재 동작 (코드 근거)

- `app/map_avoid_panel.py`: 옵션마다 체크박스 하나(비선호). 저장 `settings["map_avoid"]`(체크 순서 목록). 정규식 언어 선택은 저장하지 않는다.
- `app/map_warn.py`: 지도 `Ctrl+C` 경고는 `map_avoid`만 본다.
- `app/map_regex.py`: `"!a|b"` 제외 묶음 하나. 조각 `data/map_regex_fragments.json`(122개). 메이븐 옵션 1개는 선택 불가. 미지원 선택이 하나라도 있으면 전체 복사 차단, 250자 초과 차단, 복사 시 앱 MIME 표식.

## 3. 참고 사이트 동작 (사이트 소스로 확인)

- 따옴표 묶음을 공백으로 잇는다: 원하는 → `!`제외 → 수량 → 무리 규모 → 희귀도 → 갑충석·화폐·지도(`RegexResult.js` `buildQuotedMapRegexString`).
- 원하는 옵션은 항상 `|`로 한 묶음. `OR`/`AND`는 갑충석·화폐·지도에만 적용(`OR`이면 한 묶음, `AND`면 각각).
- 수치 조각 = 접두 + `regexCalc(값)`(`util/fnRegexCalc.js`). 한글 접두 `수량:.*`·`규모:.*`·`갑.*`·`화.*`·`지도.*`, 영문 `m q.*`·`iz.*`·`sc.*`·`cu.*`·`map.*`.

## 4. 3.30 원문과의 차이

- 실제 한글 3.30 지도 원문(`tests/trade/fixtures/fix004_nightmare_map_ko.txt` 등 5개)의 수치 줄: `아틀라스 획득물`, `아이템 희귀도`, `몬스터 무리 규모`, `지도 더 많음`, `화폐 더 많음`. `아이템 수량`은 없다.
- 3.30 패치 노트: 지도 수량 → 아틀라스 획득물, 갑충석 제거(실낱으로 대체).
- 영문 3.30 지도 원문은 아직 없다.

## 5. 방안

### 5.1 선호·비선호

- 옵션마다 `선호`·`비선호` 버튼 두 개. 선택한 버튼을 다시 누르면 해제, 반대 버튼은 전환. 메이븐 옵션은 선택 불가.
- 조각은 기존 `data/map_regex_fragments.json`(선호·비선호 공통).
  - 한 옵션에 조각이 여러 개면 그 옵션의 조각끼리는 같은 묶음 안에서 `|`.
  - `하나라도 있으면`(기본, 사이트와 같음): 모든 선호 옵션의 조각을 한 묶음 `"a|b|c"`.
  - `모두 있어야`(앱 추가, 머성 결정으로 유지): 선호 옵션마다 묶음 하나, 묶음끼리는 공백(AND).
- 지도 `Ctrl+C` 경고는 지금처럼 비선호만 본다(선호·수치 조건은 경고에 쓰지 않는다).

### 5.2 수치 조건

- 입력 범위: 빈칸 = 조건 없음. **10~999 정수** = 적용. 그 밖(1~9, 1000 이상, 소수, 숫자가 아닌 값) = 잘못된 값으로 이유를 표시하고 **복사 차단**.
- 숫자 패턴: 사이트 `regexCalc`를 그대로 옮긴다(10~999 범위에서만 쓰므로 1000 이상 `1...%` 분기는 쓰지 않음).
- **지도 속성 값의 범위**: 사이트 숫자 패턴은 지도 쪽 값이 3자리(≤999%)일 때만 올바르다. 1000% 이상이면 조건을 만족해도 놓칠 수 있다(예: 기준 999에 `+1000%`). 3.30 데이터로 계산한 상한은 모두 1000% 미만이라 지원 범위를 **지도 속성 값 999% 이하**로 정한다.
  - 계산(RePoE 3.30 `mods.min.json`, 지도 태그가 붙은 접두·접미 옵션): 접두·접미 각각 최댓값 상위 4개(8옵션, 같은 그룹 제외 규칙 무시로 실제보다 크게)의 합에 옵션 효과 최대 +50%(타락 고정 속성 +20%, 감시석 +30%)를 곱하고 고정 속성·미감정 보너스를 더한다.
  - | 속성 | 옵션 1개 최대 | 8옵션 합 | 상한 추정 |
    |---|---|---|---|
    | 아틀라스 획득물(`map_drop_scaling_+%`) | 19 | 152 | 152×1.5 + 미감정 30 = 258 |
    | 아이템 희귀도(`map_item_drop_rarity_+%`) | 56 | 400 | 400×1.5 + 고정 20 = 620. 획득물을 희귀도에도 적용하는 3.30 옵션까지 더해도 878 |
    | 몬스터 무리 규모(`map_pack_size_+%`) | 20 | 157 | 157×1.5 + 고정 10 = 246 |
    | 화폐 더 많음(`map_currency_drop_chance_+%_final_from_uber_mod`) | 64 | 344 | 516 |
    | 지도 더 많음(`map_map_item_drop_chance_+%_final_from_uber_mod`) | 40 | 285 | 428 |
  - 실제 원문 최댓값: 획득물 +90%, 희귀도 +114%, 무리 규모 +34%, 지도 +35%, 화폐 +45%(fixture 5개).
  - 지도 퀄리티 등 툴팁에 더해질 수 있는 미확인 요소가 있어 희귀도 상한의 여유는 크지 않다. 실제 원문에서 1000% 이상이 확인되면 그 속성에 4자리 분기(예: `|[1-9]...`)를 더하는 별도 수정으로 처리하고, 그 조합은 사이트 동등성 골든에서 뺀다.
- 접두(한글): 머성 결정(2026-11-20 "사이트와 정규식이 동일하다는 전제")에 따라 사이트에 있는 항목은 사이트 접두를 그대로 쓰고, 3.30에서 바뀐 항목만 실제 원문에 맞춘다.

| 앱 입력 | 한글 조각 | 근거 |
|---|---|---|
| 아틀라스 획득물 ≥ | `획득물:.*` | 사이트 `수량:.*` 자리. 3.30 원문 표기 |
| 몬스터 무리 규모 ≥ | `규모:.*` | 사이트와 같음 |
| 아이템 희귀도 ≥ | `희귀도:.*` | 앱 추가. 3.30 원문 표기 |
| 화폐 더 많음 ≥ | `화.*` | 사이트와 같음 |
| 지도 더 많음 ≥ | `지도.*` | 사이트와 같음 |

- 오탐 검사(§7.5)에서 사이트 접두가 다른 줄을 잡는 것이 확인되면, 그 항목만 속성명 + 콜론 형식(예: `화폐 더 많음: .`)으로 바꾸고 머성에게 보고한다.
- 영문: 3.30 영문 지도 원문으로 확인하기 전에는 **모든 영문 수치 조건이 미지원**이다(사이트 접두 `iz.*`·`cu.*`·`map.*`도 현행 클라이언트로 입증되지 않음). 영문 정규식을 고른 상태에서 수치 조건이 하나라도 켜져 있으면 이유를 표시하고 복사를 막는다. 조건을 비우거나 한글 정규식으로 바꾸면 복사할 수 있다.
- 화폐·지도 결합: `하나라도`(OR) → 한 묶음, `모두`(AND) → 각각. 사이트와 같다.
- 갑충석은 넣지 않는다. 실낱은 실제 원문 확인 후 별도 추가.

### 5.3 복사 차단 (기존 규칙과 같게)

다음 중 하나라도 해당하면 결과 칸을 비우고, 이유를 표시하며, 버튼과 키보드 복사를 모두 막는다.
- 지원하지 않는 선택 옵션이 있음(기존).
- 현재 언어에서 미지원인 수치 조건이 켜져 있음(5.2 영문).
- 잘못된 수치 값이 있음(5.2 범위).
- 결과가 250자를 넘음(기존).
- 선택한 옵션도 수치 조건도 없음.

### 5.4 결합 순서

선호 묶음(들) → `"!비선호"` → 아틀라스 획득물 → 몬스터 무리 규모 → 아이템 희귀도 → 화폐·지도 묶음.

### 5.5 프리셋 저장 정책

- 원본: `settings["map_presets"]` = 목록. 항목 `{id, name, order, mode, limits, limit_mode}`.
  - `id`: 생성 시 만든 고유 문자열(이름과 무관). `order`: `[[옵션키, "want"|"avoid"], …]` 선택 순서. `mode`: `any`|`all`. `limits`: 5개 키의 문자열. `limit_mode`: `or`|`and`.
- 활성: `settings["map_preset_active"]` = 활성 프리셋 `id`.
- `map_avoid`는 **활성 프리셋의 비선호 목록(순서 유지) 복사본**이다. 프리셋을 바꾸는 모든 동작(선택, 옵션 변경, 복제, 삭제)은 `load_settings()` → 프리셋·활성 ID·`map_avoid`를 함께 고침 → `save_settings()` 한 번으로 저장한다. 다른 설정 키는 그대로 둔다.
- 이름 규칙: 앞뒤 공백 제거, 1~20자, 대소문자 무시 중복 불가. 빈 이름·중복 이름으로 바꾸려 하면 이유를 표시하고 이름을 바꾸지 않는다(저장 없음). 새 프리셋은 `새 프리셋`, `새 프리셋 2` …, 복제는 `<이름> 복사본`, `<이름> 복사본 2` … 처럼 겹치지 않는 이름을 자동으로 붙인다.
- 삭제: 마지막 1개는 삭제할 수 없다(버튼 비활성). 활성 프리셋을 지우면 목록의 앞 프리셋이 활성이 된다.
- 처음 이관(1회): `map_presets`가 없으면 `기본` 프리셋을 만들고 기존 `map_avoid`를 순서대로 비선호로 넣는다. 지원하지 않는 키(카탈로그에 없음·메이븐)는 버린다.
- 복구: `map_presets`가 목록이 아니거나 항목 형식이 틀리면 틀린 항목만 버린다. 남은 항목이 없으면 이관 규칙으로 `기본`을 다시 만든다. 활성 ID가 없거나 목록에 없으면 첫 프리셋을 활성으로 한다. 이름이 비었거나 겹치면 이름 규칙으로 고친다. 복구했으면 한 번 저장한다.
- 이전 버전과의 호환: 이전 앱(v1.2.7 이하)은 `map_avoid`만 고친다. 다시 열 때 `map_avoid`가 활성 프리셋의 비선호 복사본과 다르면 **`map_avoid`를 최신으로 본다**. 활성 프리셋의 비선호를 `map_avoid` 순서대로 바꾸고, 그 옵션들의 선호 선택은 지운 뒤 저장한다. 다른 프리셋과 선호·수치 조건은 바꾸지 않는다.
- 정규식 언어: **앱 공통** 설정 `settings["map_regex_language"]`(`ko`|`en`, 기본 `ko`). 프리셋마다 저장하지 않는다.

### 5.6 화면

- 탭 이름 `비선호 지도` → `지도 옵션`. 프리셋 줄 → 보관함 정규식(언어, 선호 조건, 수치 조건, 화폐·지도 결합, 결과, 글자 수, 복사, 이유) → 필터 → 옵션 목록.

## 6. 범위 밖

- 영문 수치 조건(영문 원문 확인 후), 실낱·점술 카드 등 미확인 수치 줄, 게임 창 자동 붙여넣기, 지도 경고에 선호·수치 조건 반영.

## 7. 완료 기준

1. **사이트 동등성 골든(바꾸지 않은 공통 조합만)**: 사이트와 같은 접두(`규모:.*`, `화.*`, `지도.*`)와 같은 숫자 패턴을 쓰는 조합(선호 하나라도 · 비선호 · 무리 규모 · 화폐 · 지도, OR/AND)의 한글 정규식이 사이트 출력과 문자 단위로 같다. `regexCalc` 이식본이 10~999 모든 정수에서 사이트 함수와 같다.
2. **앱 고유 골든(별도)**: 사이트에 없는 조각(`획득물:.*`, `희귀도:.*`), `모두 있어야` 묶음, 그리고 §7.5 오탐 검사로 접두를 바꾼 항목은 사이트와 비교하지 않고 고정 기대값으로 검증한다.
3. **실제 수치 의미(지원 범위 안)**: 경계값 T ∈ {10, 15, 19, 20, 35, 89, 90, 99, 100, 105, 120, 123, 191, 200, 998}마다 각 한글 수치 조각이 지도 줄 `+(T-1)%`는 잡지 않고 `+T%`, `+(T+1)%`는 잡는다. T=999는 `+998%` 불일치, `+999%` 일치. 지도 값은 지원 범위(≤999%) 안에서만 시험한다. `(augmented)` 꼬리가 있어도 같다.
4. **값 상한 근거 재현**: §5.2의 상한 계산을 시험 데이터 생성 스크립트나 테스트로 재현해, 다섯 속성의 상한이 모두 1000 미만임을 확인한다(데이터가 바뀌어 1000 이상이 되면 실패).
5. **오탐**: 각 한글 수치 조각과, 선호로 쓰는 모든 옵션 조각을 다음 코퍼스에 대조한다. 3.30 한글 지도 원문 fixture 전체 줄, RePoE 3.30 한글 지도 옵션 문구 전체, 지도 설명·머리줄(`아이템 희귀도: 희귀`, `지도 (16등급)` 등). 수치 조각은 해당 속성 줄에만, 옵션 조각은 자기 옵션 줄에만 걸려야 한다. 걸리면 §5.2 규칙대로 바꾼다.
6. 선호: 한 옵션의 여러 조각은 묶음 안 `|`, `모두 있어야`는 옵션마다 묶음.
7. 복사 차단: §5.3 각 경우마다 결과 칸 비움, 이유 표시, 버튼·키보드 복사 모두 막힘, 이전 클립보드 유지. 정상 복사는 앱 MIME 표식 포함(지도 경고·`Ctrl+D` 오작동 방지 회귀 유지).
8. 영문: 수치 조건이 켜진 상태로 영문을 고르면 복사가 막히고, 조건을 비우면 복사된다.
9. 프리셋: §5.5의 생성·선택·이름 변경(빈·중복 거부)·복제·삭제(마지막 거부)·이관·복구·이전 버전 재진입이 각각 설정 한 번 저장으로 끝나고, 다른 설정 키가 보존되며, `map_avoid`가 활성 프리셋의 비선호와 같다.
10. 지도 `Ctrl+C` 경고는 활성 프리셋의 비선호만 쓴다(선호·수치 무시).
11. 비선호만 고른 경우(언어 한글, 수치 조건 없음)의 정규식은 v1.2.7과 바이트 단위로 같다.
12. 게임 호환: 실제 한글 클라이언트 보관함 확인 전에는 "게임에서 동작 확인" 문구를 쓰지 않는다.
