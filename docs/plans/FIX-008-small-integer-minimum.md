# FIX-008 작은 정수 옵션의 기본 최소값이 0이 되는 문제

상태: 기획안 v2, 기획 리뷰 2/3 대상(1/3 보완: 효과 표현, 적용 범위, 반전·제외 경로).

## 1. 문제와 효과

- 일반 옵션 줄의 기본 최소값은 복사 값 × 0.9를 내림한다(`app/trade/query.py` `default_minimum`). 복사 값이 정수 1이면 0이 된다.
- 오프라인 확인: 반지·목걸이 옵션만으로 12종류가 해당한다(`모든 스킬 젬 레벨 +1`, `장착된 젬 레벨 +1`, `힘 15당 피해 1% 증가` 등).
- 이 변경은 **켜진 옵션의 기본 검색 경계를 좁힌다**(최소 0 → 1). 같은 거래소 ID에서 1 미만 값이 가능한지는 확인하지 않았으므로 결과가 같다고 보장하지 않는다.

## 2. 적용 범위

- 적용 경로: `conditions()`의 일반 옵션 행(장비·주얼·플라스크·지도·고유 등)에서 기본 최소값을 정하는 부분에만 적용한다. 공용 함수 `default_minimum` 자체는 바꾸지 않는다.
- 적용 조건(모두 만족):
  - 값으로 잡힌 숫자가 **하나**이고(복수 숫자 평균 경로는 제외), 그 숫자 표기가 소수점 없는 **양의 정수 1**이다. `1.0`처럼 소수 표기는 지금과 같다.
  - 거래소 부호가 반전되는 행(`inverted`·`negate`)이 아니다. 반전 행은 UI 최소가 payload 최대(`-값`)로 직렬화되므로(`app/trade/query.py` 반전 직렬화) 지금과 같다.
  - 고정값 매처(FEAT-005), 감소(`reduced`·`less`) 옵션, 0 이하 값이 아니다.
- 결과: 기본 최소값 = `max(내림 결과, 1)` → 값 1이면 1. 값 2(→1)·3(→2) 등은 그대로다.
- **제외 경로(그대로)**: 살덩이 보조 옵션 행(`default_minimum` 호출 포함), 살덩이 단계 필수 행, 젬 레벨·퀄리티, 강탈 행, 총 원소 저항 합계 행, 보조 젬·스킬 부여 레벨 행, 묶음(`count`) 행의 기존 규칙.
- 사용자가 최소값 칸에 직접 입력한 0은 그대로 보낸다(기본값만 바꾼다).

## 3. 완료 기준

1. 단일 양의 정수 1 캡처의 일반 옵션 행은 기본 최소값 1이고, payload `min` 1이다.
2. 값 2·3, 복수 숫자 평균, 소수(`1.0` 포함), 0 이하, 감소, 고정값, 반전 행의 기본값과 payload는 지금과 같다.
3. 제외 경로(살덩이 보조·단계 행, 젬, 강탈, 총 원소 저항, 부여 레벨, 묶음 행)의 기본값·payload가 지금과 같은 회귀.
4. 사용자가 입력한 0이 그대로 전송된다.
5. 감사 전체·저장 원문 payload 비교에서 달라지는 것은 위 조건의 행의 `min` 0 → 1뿐이며, 그 행 목록을 보고한다.
