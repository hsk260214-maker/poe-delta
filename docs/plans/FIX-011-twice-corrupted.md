# FIX-011 `두 번 타락` 인식과 타락 기본 체크 복원

상태: 기획안 v2, 기획 리뷰 2/3 대상(1/3 보완: PoB 입력 매핑·중복 방지, 의도한 분류 변화, 불변 범위, payload 허용 차이). 출처: `docs/BACKLOG.md` 7번, 2026-11-20 머성 제보·결정.

## 1. 문제

- 3.30의 `두 번 타락`(영문 `Twice Corrupted`) 아이템을 타락하지 않은 아이템으로 읽는다.
  - `app/itemmodel.py`의 `FLAG_LINES`·`CORRUPT_FLAGS`에 `타락`·`Corrupted`만 있어서, `두 번 타락` 줄이 표시 줄로 잡히지 않는다.
  - 그 결과 `TradeItem.corrupted`가 거짓이 되고, 거래소 검색 창은 `타락 아님`을 체크한다.
  - 실제 원문: 머성 제보 코발트색 주얼 `천공인 눈`(마지막 표시 줄 `두 번 타락`). 파싱 결과 `flags=[]`, `corrupted=False` 재현.
- v1.2.6(FEAT-008 §4.2)은 타락한 아이템의 `타락` 체크를 기본 해제한다. 머성이 2026-11-20 "타락한 아이템은 타락을 체크한 상태로" 되돌리기로 결정했다.

## 2. 방안

1. `두 번 타락`·`Twice Corrupted`를 표시 줄(`FLAG_LINES`)과 타락 표시(`CORRUPT_FLAGS`)에 추가한다.
   - 거래소 검색은 기존 `corrupted: true` 조건을 그대로 쓴다. `두 번 타락` 전용 조건(`twice_corrupted`)은 확인 전이라 쓰지 않는다.
   - **PoB 입력**: `compose_en()`은 표시 줄을 별도 블록에 그대로 넣는다. PoB가 `Twice Corrupted`를 이해한다는 근거가 없으므로, PoB에 넘길 때는 한글·영문 모두 PoB가 아는 `Corrupted`로 바꾼다(`ko2en.FLAGS["두 번 타락"] = "Corrupted"`, 영문 경로도 같은 매핑).
   - **중복 방지**: 한 원문에 `타락`과 `두 번 타락`이 함께 있어도 PoB 입력의 `Corrupted`는 한 번만 넣는다.
2. `app/trade/templates.py`에서 지역 레벨이 아닌 템플릿의 타락 해제 규칙을 없앤다. 그러면 v1.2.5처럼 타락한 아이템은 `타락`, 타락하지 않은 아이템은 `타락 아님`이 체크된 상태로 열린다.
   - 지역 레벨 템플릿(지도·강탈)은 바꾸지 않는다. 레벨 조건만 체크하고 타락을 포함한 나머지는 해제한다(FEAT-008 §4.1).

## 3. 영향과 불변 범위

- `model.flags`를 쓰는 곳: 거래소 `item_info()`의 타락·영향력 판정, `itemmodel.classify_implicits()`의 고정 속성 분류, `compose_en()`의 PoB 입력.
- **의도한 변화**
  - `두 번 타락` 아이템이 타락으로 판정된다.
  - 고급 복사 머리줄이 없는 **일반 복사**의 `두 번 타락` 아이템에서, `classify_implicits()`가 고정 속성을 바알(타락) 고정 속성으로 분류할 수 있다. 베이스 고정 속성과 총주교·포식자 속성의 기존 우선순위는 그대로 둔다.
- **불변**
  - 메모 줄(`메모:`/`Note:`)과 옵션 줄 목록은 바뀌지 않는다. `두 번 타락`은 옵션 줄이 아니라 표시로만 남는다.
  - `타락` 줄만 있는 아이템의 파싱과 고정 속성 분류는 바뀌지 않는다(기본 체크는 §2.2에 따라 바뀜).
  - 고급 복사(`{ … }` 머리줄 있음)의 고정 속성 분류는 머리줄을 따르므로 바뀌지 않는다.

## 4. 범위 밖

- 거래소 `두 번 타락` 전용 조건, 다른 3.30 신규 표시 줄 조사.

## 5. 완료 기준

1. 실제 원문 `천공인 눈`: `corrupted=True`, 검색 창 라벨 `타락`, 기본 체크, 쿼리 `misc_filters.corrupted = "true"`. 옵션 줄 목록과 메모 처리는 지금과 같다.
2. 영문 `Twice Corrupted` 파생 fixture(파생 표시): 같은 결과.
3. 타락한 장비·젬·플라스크: `타락` 체크. 타락하지 않은 아이템: `타락 아님` 체크. 금지된 서·살덩이: 지금처럼 숨김.
4. 지역 레벨 템플릿의 기본값은 v1.2.6과 같다.
5. PoB 입력: `두 번 타락`(한글·영문)은 `Corrupted` 한 줄로 들어간다. `타락`과 함께 있어도 `Corrupted`는 한 번이다. `Twice Corrupted`라는 줄은 PoB 입력에 없다. 아이템 옵션 목록에 새 줄이 생기지 않는다.
6. 고정 속성 분류: 일반 복사의 `두 번 타락` 아이템만 바알 분류가 바뀌고, 베이스·총주교·포식자 분류와 `타락` 아이템, 고급 복사는 ff866c9와 같다.
7. 기본 검색 payload를 ff866c9와 비교한다. 허용 차이는 다음뿐이다.
   - 지역 레벨이 아닌 기존 타락 아이템: v1.2.6에서 빠졌던 `corrupted: true` 필터 복원.
   - 지역 레벨이 아닌 `두 번 타락` 아이템: `corrupted` 값 `false` → `true`.
   - 지역 레벨 템플릿 아이템과 타락 조건을 숨기는 품목(금지된 서, 살덩이): payload 동일.
