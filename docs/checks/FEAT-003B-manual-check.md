# FEAT-003B 출시 전 브라우저 확인

카카오 거래소 Standard 검색이다. 브라우저에서 아래 링크를 하나씩 열어 `가판대`, `타락 아님`, 표의 베이스·등급·지도 정체성 조건이 채워졌는지 확인한다. 매물이 있으면 상세 표시의 등급과 해당 고정 옵션도 확인한다. 조건이 빠지거나 매물이 없거나 보안 확인에 막히면 미확인으로 남긴다.

**결과: 2026-11-18 머성이 카카오 링크 11개로 확인했고 전부 통과했다. `BROWSER_VERIFIED`에 반영되었다.**

앱은 공식 API와 브라우저를 모두 확인한 값만 허용한다.

1. 일반 반지 링크는 결과가 모두 일반 등급인지 본다. 지도 링크는 각 결과에 표의 수호자 점령·성채·지역 영향 고정 옵션이 실제로 붙었는지 본다. 그 식별값이 없는 매물이 섞이면 통과시키지 않는다.
2. 결과를 확인한 값만 `app/trade/items.py`의 `BROWSER_VERIFIED`에 추가한다. 일반 등급 키는 `normal`이며, 지도는 각 링크의 `implicit.stat_…|N` 전체 ID를 쓴다. 이 키는 공식·카카오 서버와 관계없이 같다.
3. 일반 반지 링크는 정확한 베이스(`토파즈 반지`) 검색이다. 장비 종류 기본 검색과는 다르며, 일반 등급 조건 확인용이다.
