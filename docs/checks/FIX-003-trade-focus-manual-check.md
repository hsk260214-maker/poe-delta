# FIX-003 머성 확인 목록

1. 아이템 툴팁이 보일 때 `Ctrl+D`로 거래소 창을 연다. 툴팁이 남는지 확인한다. 남으면 발생 시각과 `%LOCALAPPDATA%\PoeDelta\trade-focus.log`에서 같은 `open_id`의 `open`, `close`, `after_hide` 분기를 기록한다. 복귀 조건이 성립하지 않으면 `after_hide`는 기록되지 않는다.
2. 거래소 창이 앞에 있을 때 `Esc`와 `닫기` 버튼을 각각 사용해 게임 입력이 바로 되는지 확인한다. 제목 표시줄 X나 `Alt+F4` 종료는 `system`으로 기록된다.
3. 활성화가 거부되면 창은 보이고 “거래소 창을 클릭하면 입력할 수 있습니다”가 표시되는지 확인한다. 창 밖의 `Esc`로는 거래소가 닫히지 않아야 하며, 거래소 창을 직접 클릭해 활성화하면 안내가 사라져야 한다.
4. 브라우저나 다른 앱이 앞에 있을 때 거래소 창을 닫아도 포커스를 빼앗지 않는지 확인한다. 이미 게임이 앞이면 별도 복귀 동작이 없어야 한다.
5. 관리자 권한으로 실행된 게임에서도 위 동작을 확인한다. 권한 차이로 복귀가 거부되면 재시도하지 않으므로 게임 창을 직접 클릭한다.

`synthetic_alt: 0`은 거래소 창의 포커스 처리에만 해당한다. 이 값이 0인데도 툴팁이 남는다면 다음 조사 후보는 복사 경로의 합성 Ctrl up이며, 이번 변경 범위에는 포함하지 않았다.
