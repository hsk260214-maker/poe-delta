# FEAT-001 개발판 수동 확인

기준: `docs/plans/FEAT-001-trade-search.md` v4.3. 아래 게임·브라우저 동작은 머성이 확인할 항목이며, 개발 세션의 자동 테스트 통과와 별개다.

## 사용 방법

1. 게임의 아이템 위에서 `Ctrl+D`를 누르거나 옵션변경 창의 "거래소 검색"을 누른다. 두 경로 모두 복사해 온 원본 아이템을 사용하며, 창을 열기만 해서는 검색하지 않는다.
2. 리그와 옵션 체크·최소·최대값을 확인한다. 기본 브라우저 모드에서는 리그가 비었으면 먼저 입력한다.
3. 검색 버튼 또는 `Enter`로 검색한다. 두 모드 모두 가판대(즉시 구매, `securable`) 매물만 검색한다.

기본 브라우저 모드에서는 프로그램의 거래소 HTTP 요청이 0회다. 레어·유니크 장비와 주얼만 지원하고, 맞추지 못한 옵션은 회색으로 제외한다. 조건이 너무 길면 켠 옵션을 줄인다.

메뉴의 "거래소 설정"에서 모드·서버·리그·최소값 비율·단축키를 바꾼다. 카카오는 한글 아이템에서만 지원한다. 게임 위 시세 모드는 검색 버튼을 눌렀을 때 최대 20개 가격과 요약을 보여 주며, 조건 변경만으로 다시 검색하지 않는다.

**게임 위 시세 모드는 공식 문서 밖 내부 API를 쓰므로 계정 정지 위험이 있다.** GGG는 허용을 보장하지 않으며 위험은 사용자 계정이 부담한다. 위험 안내를 확인해야 켤 수 있다. 선택 입력인 POESESSID는 Windows 사용자별 DPAPI로 암호화하고 공식 서버에만 보내며, 설정 파일과 브라우저 링크에는 넣지 않는다.

거래소 기능은 위험 확인된 게임 위 시세 모드에서만 선택한 공식 서버 또는 `poe.kakaogames.com`으로 검색 조건을 보낸다. README의 원본 접속처 안내와 별도로 이 개발판 동작을 확인한다.

개발판 배포 전에는 자동 업데이트 대상 문제(FIX-001)를 먼저 해결해야 한다. `app/app_update.py`는 수정하지 않았다.

## 머성 확인 목록

- PoE가 앞에 있을 때만 `Ctrl+D`가 작동하고, 다른 프로그램의 `Ctrl+D`는 그대로인지 확인한다. "게임 Ctrl+C 감지"를 꺼도 거래소 단축키는 동작해야 한다.
- 창이 커서 근처·화면 안에 뜨는지 확인한다. 사용자가 옮기지 않은 채 닫았다가 커서를 다른 곳에 두고 다시 열면 새 커서 근처에 떠야 한다. 사용자가 끌어 옮긴 뒤에는 그 위치를 기억해야 한다.
- 창을 열어 둔 채 다른 아이템에서 `Ctrl+D`를 누르면 창이 새 커서 근처로 옮겨지고, 그 뒤 닫았다 다시 열어도 그 자리에 고정되지 않는지 확인한다 (자동 이동이 사용자 이동으로 저장되는지 실제 Windows에서만 확인 가능).
- 입력 포커스와 `Esc` 닫기 후 게임 포커스 복귀를 확인한다. 게임으로 돌아가 새 아이템에 `Ctrl+D`를 누르면 같은 창의 내용이 바뀌어야 한다.
- 옵션변경 창에서 줄을 끄거나 수치를 바꾸거나 가상 옵션을 추가한 뒤 "거래소 검색"을 눌러도, 원본을 `Ctrl+D`로 열었을 때와 같은 조건이 나와야 한다.
- 기존 아이템 `Ctrl+C`는 옵션변경 창, 지도 `Ctrl+C`는 지도 경고 창으로 가는지 확인한다. 지도 창의 포커스·`Esc` 복귀와 캐릭터 자동 갱신도 확인한다.
- 공식·카카오 브라우저 링크에 베이스·유니크 이름·옵션·가판대 조건이 채워지는지 확인한다. 가장 긴 정답 샘플은 `tests/trade/fixtures/browser_links.json`의 `rare_ko_kakao`이며 **981자**다. 이 링크도 잘리지 않고 열려야 한다.
- 게임 위 시세 모드 전환 시 위험 안내의 기본 선택이 "취소"인지, 취소·동의·브라우저 복귀가 동작하는지 확인한다. 검색 후 가격순 결과·요약과 "거래소에서 열기"가 같은 검색을 가리켜야 한다.

## 개발 테스트

`python -m pip install -r requirements-dev.txt` 후 저장소 루트에서 `python -m pytest tests`로 실행한다. 네트워크는 차단하고 사용자 데이터·도구 cache·출력은 임시 폴더로 격리한다. pytest cacheprovider는 사용하지 않는다.
